# Event Ticketing System

## Overview

This is a Java-based Event Ticketing System that allows users to book tickets for various events. The system supports different types of seats such as Regular and VIP, and manages bookings and events efficiently.

## Features

* Create and manage events
* Book tickets for events
* Support for multiple seat types (Regular, VIP)
* Ticketing service to handle booking logic
* Easy-to-use Java console application structure

## Project Structure

* `/one/Booking.java` - Handles booking logic
* `/one/Event.java` - Event details and management
* `/one/RegularSeat.java` - Regular seat implementation
* `/one/VIPSeat.java` - VIP seat implementation
* `/one/Seat.java` - Base seat class/interface
* `/one/TicketingService.java` - Main service for ticket bookings
* `/one/TicketAppMain.java` - Main class to run the application

## Getting Started

### Prerequisites

* Java JDK 8 or higher
* IDE such as Eclipse, IntelliJ IDEA, or VS Code
* Git

### How to Run

1. Clone the repository:

```bash
git clone https://github.com/tharikaleet06/EventTicketingSystem.git
```

2. Open the project in your preferred IDE.

3. Alternatively, compile and run using the command line:

```bash
javac one/*.java
java one.TicketAppMain
```
